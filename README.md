# Claude Panel

**Obsidian 안에서 Claude Code와 대화하고, 노트를 검토하고, 선택한 문장을 고쳐 쓰는 데스크톱 플러그인입니다.**

로컬에 설치된 Claude Code를 Obsidian 사이드바에서 실행합니다. Vault를 작업 폴더로 사용하며, Claude Code의 사용자·프로젝트·로컬 설정과 `CLAUDE.md`, 스킬을 활용합니다. 별도의 플러그인용 API 키 입력 없이 기존 Claude Code 인증 환경을 사용합니다.

## 주요 기능

- **사이드바 대화** — 응답을 실시간으로 확인하고, 여러 패널에서 독립적인 대화를 진행합니다. 생각·도구 실행 내역은 접어 볼 수 있고, 필요한 도구 승인은 대화 안에서 처리합니다.
- **노트와 선택 영역 연결** — 현재 노트 경로와 선택한 텍스트를 대화에 첨부합니다. 전송 전에 첨부 내용을 미리 보거나 제외할 수 있습니다.
- **선택 영역 고쳐쓰기** — 수정 지시를 입력하고 원문과 변경 내용을 비교한 뒤 노트에 적용합니다.
- **대화 이어가기** — 최근 대화를 검색해 다시 열고, 기존 대화에서 분기하거나 이름을 변경합니다.
- **모델·추론·권한 선택** — 입력창 아래 한 줄에서 설정을 바꿉니다. 긴 선택 목록은 메뉴로 열리고, 버튼에 마우스를 올리면 설명을 확인할 수 있습니다.
- **계정 사용량 확인** — 제공되는 5시간·주간·모델별 한도와 초기화 시각을 확인합니다. 상세 팝업은 대화 출력 영역을 줄이지 않습니다.
- **슬래시 명령과 스킬** — 입력창에 `/`를 입력해 현재 Claude Code 세션이 제공하는 명령과 스킬을 찾습니다.

## 설치

### 준비 사항

- Obsidian 데스크톱 1.5.0 이상. 모바일은 지원하지 않습니다.
- 같은 컴퓨터에서 실행·인증이 완료된 Claude Code. 먼저 터미널에서 `claude`로 대화할 수 있는지 확인하세요.
- 소스 빌드에 사용할 Node.js와 npm.

### 소스에서 빌드해 설치하기

```bash
git clone https://github.com/kaym9n/claude_panel.git
cd claude_panel
npm ci
npm run build
```

빌드 후 Vault의 `.obsidian/plugins/claude-panel/` 폴더를 만들고 다음 세 파일을 복사합니다.

```text
<Vault>/.obsidian/plugins/claude-panel/
├── main.js
├── manifest.json
└── styles.css
```

`main.js`는 빌드로 생성됩니다. 저장소 소스만 복사해서는 플러그인이 실행되지 않습니다.

macOS·Linux에서는 복사 대신 빌드 결과를 연결하는 스크립트를 사용할 수도 있습니다. 경로를 실제 Vault 위치로 바꿔 실행하세요.

```bash
bash scripts/link-vault.sh "/path/to/your/vault"
```

이 방식은 세 파일을 소스 폴더에 심볼릭 링크하므로 소스 폴더를 유지해야 합니다.

Obsidian을 다시 열고 **설정 → 커뮤니티 플러그인**에서 Claude Panel을 활성화합니다. 이후 명령 팔레트에서 **Claude Panel: Open panel**을 실행하거나 리본의 봇 아이콘을 클릭합니다.

업데이트할 때는 소스를 갱신하고 다시 빌드한 뒤 세 파일을 교체합니다. 심볼릭 링크로 설치했다면 다시 복사할 필요 없이 플러그인을 껐다 켜면 됩니다.

## 사용법

### 노트를 보며 대화하기

1. 작업할 노트를 열고 Claude Panel을 엽니다.
2. 필요한 경우 노트에서 텍스트를 선택합니다.
3. 입력창 위의 첨부 칩을 눌러 내용을 확인합니다. 제외할 항목은 `×`로 제거합니다.
4. 요청을 입력하고 전송합니다. 예: “현재 노트의 핵심 내용을 요약해 줘”, “선택한 문장에서 빠진 전제를 찾아 줘”.

현재 노트는 **경로만** 전달하며, 본문이 필요하면 Claude가 도구로 읽습니다. 선택 영역은 **선택한 텍스트와 위치**를 전달합니다. `/` 명령을 보낼 때는 노트·선택 영역을 첨부하지 않습니다.

응답 아래 복사 아이콘으로 원문을 복사할 수 있습니다. 이전 대화를 읽는 동안에는 스크롤을 강제로 내리지 않으며, 최신 응답으로 이동하는 버튼을 제공합니다. 응답 중에는 전송 버튼이 중단 버튼으로 바뀝니다.

### 모델과 권한 바꾸기

입력창 아래에는 **권한 · 컨텍스트 · 모델 · 추론 강도 · 계정 한도 · 전송**이 한 줄로 배치됩니다.

- **모델**: 버튼을 눌러 선택합니다. 실제 응답 모델은 응답이 시작된 뒤 버튼 툴팁에서 확인할 수 있습니다.
- **추론 강도**: 선택한 모델이 지원하는 수준을 고릅니다. 모델이 지원하지 않으면 해당 버튼은 숨겨집니다.
- **권한**: 방패 등의 아이콘을 눌러 기본·편집 자동·계획·auto 모드를 선택합니다. 실제 사용 가능 여부는 Claude Code 환경에 따릅니다.

도구 승인이 필요하면 대화에 승인 카드가 나타납니다. 연결·생각·도구 실행·승인 대기·완료 등의 진행 상태는 패널 상단 아이콘과 툴팁에서 확인합니다.

### 사용량 확인하기

**컨텍스트 사용률**은 현재 대화의 기억 공간, **계정 한도 게이지**는 계정의 사용 한도입니다. 두 수치는 서로 다른 기준입니다.

계정 한도 게이지를 클릭하면 제공되는 한도별 사용률, 초기화 시각, 마지막 확인 시각을 볼 수 있습니다. 새로고침 버튼과 Claude 공식 사용량 페이지 링크도 제공합니다. 시간은 기기의 현지 시간으로 표시합니다.

한도는 첫 메시지를 보내기 전에도 조회하며 여러 패널이 조회 결과를 공유합니다. 한도 도달·경고는 색상으로, 조회 실패는 `!`로, 오래된 값은 점선 밑줄로 구분합니다. 상세 팝업에서 상태 설명과 마지막 확인값을 확인하세요. 계정이나 인증 환경에서 한도를 제공하지 않으면 미지원으로 표시하며, 이를 0%나 무제한으로 해석하지 않습니다.

현재 제공하는 사용량 화면은 계정 한도 중심이며, 누적 토큰·비용 상세 집계는 제공하지 않습니다.

### 이전 대화 이어가기

상단 기록 아이콘 또는 **Open thread…** 명령으로 최근 대화를 검색합니다.

| 대화 목록 단축키 | 동작 |
| --- | --- |
| `Enter` | 선택한 대화 이어가기 |
| `Ctrl/Cmd+Enter` | 선택한 대화에서 분기해 새 대화 열기 |
| `F2` | 대화 이름 변경 |

상단 `+` 버튼은 새 대화를 시작합니다. 기존 패널을 유지하면서 별도 대화를 시작하려면 **Open new panel** 명령이나 더보기 메뉴의 **새 패널 열기**를 사용하세요.

### 선택한 문장 고쳐쓰기

1. 노트 편집기에서 수정할 텍스트를 선택합니다.
2. 명령 팔레트에서 **Claude Panel: Rewrite selection**을 실행합니다.
3. “더 간결하게”, “존댓말로 바꿔 줘” 등의 지시를 입력하고 **생성**을 누릅니다.
4. 추가·삭제된 부분을 비교한 뒤 **적용**을 누릅니다. 취소하면 적용하지 않습니다.

생성 중 원문이 바뀌었다면 다시 생성한 뒤 적용해야 합니다.

## 단축키와 명령

### 입력창 단축키

| 단축키 | 동작 |
| --- | --- |
| `Enter` | 메시지 전송. 설정에서 변경 가능 |
| `Ctrl/Cmd+Enter` | 메시지 전송 |
| `Shift+Enter` | 줄바꿈 |
| `Shift+Tab` | 권한 모드 순환 |
| `Esc` | 진행 중인 응답 중단 |
| `/` | 명령·스킬 자동완성 |

상단 키보드 아이콘으로도 단축키 안내를 확인할 수 있습니다.

### 명령 팔레트

아래 명령은 모두 `Claude Panel:` 접두어로 표시됩니다.

| 명령 | 기능 |
| --- | --- |
| Open panel | 기존 패널을 열거나, 없으면 생성 |
| Open new panel | 독립 세션을 사용하는 새 패널 열기 |
| New chat | 현재 패널에서 새 대화 시작 |
| Open thread… | 최근 대화 검색·열기·분기·이름 변경 |
| Rewrite selection | 선택 영역 고쳐쓰기 |
| Test connection | Haiku에 실제 요청을 보내 연결 확인 |
| Copy diagnostics | 버전·실행 경로·최근 오류 등의 진단 정보 복사 |

## 설정

**Obsidian 설정 → Claude Panel**에서 변경합니다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| Claude 실행 파일 경로 | `claude` | 자동으로 찾지 못하면 **자동 찾기**를 누르거나 절대 경로 입력 |
| 기본 모델 | 비어 있음 | Claude Code 설정을 따름. `opus`, `sonnet`, `haiku` 등 지정 가능 |
| 현재 노트 자동 첨부 | 켜짐 | 전송할 때 활성 노트 경로를 컨텍스트로 첨부 |
| 전송 단축키 | `Enter` | `Ctrl/Cmd+Enter`로 변경 가능 |
| 사용자 hook 사용 | 켜짐 | 끄면 패널 세션에서 사용자 설정의 hook을 실행하지 않음. 새 대화부터 적용 |

## 문제 해결

**Claude 실행 파일을 찾지 못할 때**

설정의 **자동 찾기**를 실행하세요. 계속 실패하면 터미널에서 사용하는 Claude 실행 파일의 절대 경로를 지정합니다.

**패널 연결이나 응답에 문제가 있을 때**

터미널에서 Claude Code가 정상 실행되고 인증되어 있는지 확인한 뒤 **Test connection**을 실행하세요. 이 명령은 실제 모델 호출이므로 사용량이 발생할 수 있습니다. 문제가 계속되면 **Copy diagnostics**로 진단 정보를 확인할 수 있습니다.

**사용량이 표시되지 않거나 갱신되지 않을 때**

계정 한도 팝업에서 새로고침을 누르고 상태 설명을 확인하세요. 조회 실패 시 마지막 성공값을 유지합니다. 미지원 환경에서는 팝업의 공식 사용량 링크를 이용할 수 있습니다.

**전송 실패 후 입력을 되찾고 싶을 때**

입력창이 비어 있으면 실패한 입력을 자동 복원합니다. 이미 새 초안을 작성 중이면 초안을 유지하고, 복원 아이콘으로 실패한 입력을 추가할 수 있습니다.

## 개발 및 검증

```bash
npm ci
npm test           # 실제 CLI 호출 없는 단위 테스트
npm run build      # 타입 검사, 번들 생성, 번들 로드 검사
npm run dev        # 변경을 감지하며 빌드
```

실제 Claude Code 환경의 통합 검증은 `npm run test:live`로 실행합니다. 실제 모델 호출을 포함합니다. SDK·CLI 변경 후 스트림 fixture를 갱신하려면 `scripts/record-fixture.sh`를 사용합니다.
