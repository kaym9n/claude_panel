# Claude Panel

Obsidian 사이드바에서 로컬 Claude Code를 쓰는 개인용 플러그인. vault의 `CLAUDE.md`·스킬·hook·권한 설정이 터미널과 똑같이 적용된다.

## 설치 (개발 빌드)

```bash
npm install
npm run build
scripts/link-vault.sh ~/Vault/Boxx      # main.js·manifest.json·styles.css만 심볼릭 링크
```

Obsidian에서 Claude Panel을 켜고 **Claude Panel: Test connection**으로 확인한다.
Obsidian이 `claude`를 못 찾으면 설정 › Claude 실행 파일 경로에서 [자동 찾기]를 누른다.

## 명령

| 명령 | 설명 |
|---|---|
| Open panel / Open new panel | 패널 열기 / 새 패널(독립 세션) 열기 |
| New chat | 포커스된 패널에서 새 대화 |
| Open thread… | 스레드 목록 (Enter 열기, Ctrl+Enter fork, F2 이름 변경) |
| Rewrite selection | 선택 영역 고쳐쓰기 (단어 diff 확인 후 적용) |
| Copy diagnostics | 버전·경로·최근 오류를 클립보드로 |
| Test connection | haiku로 1회 호출해 연결 확인 |

입력창: Enter 전송(설정 가능), Shift+Enter 줄바꿈, Shift+Tab 권한 모드 순환, Esc 중단, `/` 명령·스킬 자동완성.

## 개발

### 계정 한도 (P0)

입력창 아래의 **계정 한도 게이지**를 클릭하면 팝업에서 5시간·주간·모델별 한도와 초기화 시각을 확인할 수 있다. 같은 줄의 **컨텍스트**는 대화 기억 공간이며 계정 한도와 별개다. 팝업을 열어도 대화 출력 영역은 줄어들지 않는다.

- 첫 메시지 전에도 조회하며, 모델에 프롬프트를 보내지 않는다. 조회용 CLI는 hook·도구·세션 저장을 끄고 제어 요청 후 종료한다.
- 여러 패널은 한도 조회와 60초 캐시를 공유한다. 보이는 패널에서 캐시 만료 시 갱신하고, 새로고침 버튼으로 즉시 재조회할 수 있다. 실패하면 자동 재시도 간격을 최대 5분까지 늘린다.
- 조회 실패는 마지막 성공값과 확인 시각을 유지한다. 미지원·미제공·초기화 시각 경과는 0%나 무제한으로 표시하지 않는다.
- 실시간 한도 경고를 표시하며, 초기화 시각은 기기 현지 시간이다. 공식 사용량 페이지 링크도 제공한다.
- SDK의 실험적 usage API 의존성은 `src/usage/readUsage.ts`에 격리했다. API 변경 시 이 계층을 먼저 확인한다. 비용·누적 토큰 상세는 후속 P2 범위다.

### 일상 사용 UI (P1)

- 입력창 아래에서 모델·추론·권한을 선택한다. 모델 버튼의 툴팁에서 CLI 초기화와 응답 이벤트로 확인한 실제 모델을 표시하며, 연결 전에는 확인 대기 안내를 제공한다. 적용 실패 시 기존 선택을 유지한다.
- 연결·생각·도구 실행·승인 대기·재시도·압축·완료 상태를 패널 상단 아이콘과 툴팁으로 표시한다. 생각과 도구 내역은 작업 묶음으로 접고 펼칠 수 있으며, 승인 카드는 묶음 밖에 유지한다.
- 응답 아래 **복사**로 원문을 복사한다. 위쪽 대화를 읽는 동안에는 자동으로 아래로 끌어내리지 않고 **최신 응답** 버튼을 제공한다.
- 첨부 칩을 클릭하면 전달할 노트 경로와 선택 텍스트를 미리 볼 수 있다. ×로 제외할 수 있고, `/` 명령에는 첨부하지 않는다.
- 전송 실패 시 빈 입력창에는 입력을 복원한다. 새 초안을 작성 중이면 보존하고 **실패한 입력 추가**로 합칠 수 있다.
- 최근 대화 검색에서 현재 대화를 구분하고, 기록 복원 중·완료·실패 상태를 표시한다.

### 아이콘 중심 스타일

전송·중단·복사·새로고침·첨부 제거·최신 응답 이동은 Obsidian Lucide 아이콘으로 표시한다. 아이콘 버튼은 툴팁·접근성 이름·키보드 포커스를 제공한다. 권한·컨텍스트·모델·추론·계정 한도·전송을 입력창 아래 한 줄에 배치한다. 모델·추론·권한은 짧은 버튼과 선택값에 체크 표시가 있는 메뉴로 제공하며, 계정 한도는 요약 수치와 팝업 상세로 구분한다. 키보드 아이콘으로 단축키 설명을 펼칠 수 있다.

### 검증

- `npm test` — 단위 테스트 (실제 CLI 불필요)
- `npm run test:live` — 실제 CLI 통합 테스트 (임시 폴더, haiku, hook 끔)
- `npm run build` — 타입 검사 + 번들 + 번들 로드 검사
- `scripts/record-fixture.sh` — normalize 회귀 테스트용 실제 스트림 재녹화 (SDK·CLI 업데이트 후)
- SDK는 `@anthropic-ai/claude-agent-sdk@0.3.278`로 고정. 올릴 때는 fixture를 다시 녹화하고 `npm test && npm run test:live`를 통과시킨다.
